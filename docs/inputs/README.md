# Vstupní podklady – Projekt Tagery (obecné)

Sem patří veškeré obecné podklady k projektu, ze kterých agenti čerpají při tvorbě dokumentace a specifikací.

## Co sem nahrávat
- Zadání od klienta (PDF, DOCX, odkaz)
- Business požadavky a cíle projektu
- Konkurenční analýzy a inspirace
- Poznámky z meetingů
- Výzkumné materiály (NotebookLM export, Perplexity shrnutí)
- Wireframy a mockupy (obecné)

## Co sem nepatří
- Modul-specifické podklady → `docs/modules/<modul>/inputs/`
- Podklady pro konkrétní EPIC → `tasks/<EPIC>/inputs/`
- Podklady pro konkrétní stage → `stages/<stage>/inputs/`
